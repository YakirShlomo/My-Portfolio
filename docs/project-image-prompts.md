# Project cover images

Generated with the built-in image_gen tool. Conceptual illustrations, not screenshots of the products.

Sources: project descriptions in src/data/projects.js; Tula.y public page title and description at https://tula-y.com.

## Original generation prompt

Use case: stylized-concept. Asset type: portfolio project cover image. Create one refined understated editorial 3D still life. Wide landscape composition 3:2, centered objects with generous negative space, all important objects inside middle 65 percent so image can crop. Warm ivory, muted slate, desaturated sage and pale cyan accents. Matte ceramic, frosted glass, fine paper, soft diffuse daylight, gentle contact shadows, quiet premium art direction. Neutral warm gray seamless backdrop. No text, letters, logos, watermarks, UI screenshots or busy decorations.

## Palette revision

All eight covers were edited individually with the built-in image_gen tool using their original cover as the edit input, then saved over the corresponding WebP asset listed above. The user requested alignment with the site palette in src/styles/tokens.css.

Shared edit prompt: Preserve the exact subject, recognizable objects, their positions and composition, landscape 3:2. Change palette, materials colors and lighting to integrate seamlessly into the dark portfolio. Background and floor: near-black charcoal #07070a to #131319. Objects: graphite, smoked glass, cool silver-gray #a8a8b3 with selective off-white #f3f3f5 highlights; delicate muted cyan #6fc7d6 accents and rim light. Replace beige, cream, warm brown and sage/olive with cool charcoal/silver/teal. Flowers may be cool silver-white, foliage desaturated dark teal. Soft controlled studio light, visible detail, subdued elegant mood. No harsh neon, saturated blue, extra objects, text, logos or watermark. The overall image must read as dark.
